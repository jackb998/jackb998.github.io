File tools, thoughtfully arranged · app per macOS

Un'app per la barra dei menu di macOS che trasforma un trascinamento in una conversione: mentre trascini un file dal Finder, premi ⇧ Shift e una ruota mostra i formati per quel tipo di file. Funziona con immagini, PDF, video, audio, documenti, fogli di calcolo e presentazioni. Tutto avviene sul Mac: nessun file viene caricato online.

Sviluppata in Swift con i framework di Apple, disponibile in italiano, inglese e francese. Gratuita e open source (licenza MIT).

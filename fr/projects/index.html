File tools, thoughtfully arranged · application pour macOS

Une application de barre des menus pour macOS qui transforme un glisser-déposer en conversion : pendant que vous faites glisser un fichier depuis le Finder, appuyez sur ⇧ Maj et une roue affiche les formats pour ce type de fichier. Elle fonctionne avec les images, PDF, vidéos, fichiers audio, documents, tableurs et présentations. Tout se passe sur le Mac : aucun fichier n'est envoyé en ligne.

Développée en Swift avec les frameworks d'Apple, disponible en français, anglais et italien. Gratuite et open source (licence MIT).
